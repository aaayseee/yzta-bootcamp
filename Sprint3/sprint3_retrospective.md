# Sprint 3 Retrospective

## İyi gidenler

- Canlı ortamda API kesintisine dayanıklı tahmin yaklaşımı geliştirildi.
- Yönetim portalının giriş ve entegrasyon deneyimi görünür şekilde ilerledi.
- Koyu tema ve grafik bağımlılıkları dağıtım paketine dahil edildi.

## İyileştirilmesi gerekenler

- Demo entegrasyonları gerçek başarı olarak gösterilmemeli.
- Parola, davet kodu ve oturum bilgileri kaynak kodda veya tarayıcı depolamasında tutulmamalı.
- CSV, SQLite ve MySQL olarak ayrılan kayıt akışları tek veri kaynağında birleşmeli.
- Her ürün artımı için otomatik açılış ve API testi bulunmalı.
- Bağımlılık sürümleri tekrarlanabilir kurulum için sınırlandırılmalı.

## Sprint 4 aksiyonları

1. Güvenli parola hashleme ve rol tabanlı erişim.
2. Merkezi SQLite/MySQL repository katmanı.
3. Tahmin geçmişini CSV yerine veritabanından okuma.
4. Streamlit açılış, kullanıcı ve API testleri.
5. Öncelikle Telegram için gerçek entegrasyon.
